Python 簡介 (Python Overview)

Python 程式語言的核心觀念與特色解析

Python 是一種直譯式 (Interpreter) 的電腦程式語言 (Programming Language)，具有物件導向 (Object-oriented) 的特性。

Python 的四大核心特色

1

免費且開源

Open Source 自由軟體，全球開發者皆可免費下載使用與改進原始碼。

2

簡單易學

語法簡潔清晰，貼近自然英文，大幅降低初學程式設計的門檻。

3

移植性較高

可在 Windows、macOS、Linux 等多種不同作業系統平台上無縫執行。

4

豐富第三方套件

擁有龐大的 Package 生態系，涵蓋 AI、數據分析、網頁爬蟲與遊戲開發。

輸入程式碼 (Programming) 與運算思維

運算思維解析：何謂原始程式碼 (Source Code) 以及開發者與使用者的維度差異。

💡

何謂「程式碼」(Source Code)？

在文字編輯器中輸入的程式指令，一般稱為原始程式碼 (Source Code)，或簡稱為程式碼。

創作者角色

寫程式的人 (Developer)

必須運用運算思維 + 程式語言，根據輸入資料想出運算過程（即演算法設計），進而產生正確的輸出資料。

1. 問題分析 ➔
2. 思考解題步驟 (演算法設計) ➔
3. 程式撰寫 (寫入 Source Code) 完成
使用者角色

使用者 (User)

使用者執行軟體時，無需了解內部的演算法細節，僅需要知道要輸入的資料以及獲得的輸出結果即可。

輸入資料 (Input): 使用者操作/資料
軟體執行 (Execution): 背景黑盒子運算
輸出資料 (Output): 最終結果顯示
簡單、直覺的互動介面是使用者最關心的核心體驗。

Python 基礎語法：註解 (Comments)

重點解析：註解是用來為程式碼提供說明，直譯器會自動忽略不執行。

1. 單行註解

#

使用井字號 # 開頭，其後方該行的文字皆會被視為註解。

# 這是一行單行註解
print("Hello World") # 可以在程式碼後方註解

2. 多行註解

""" ... """

使用三個雙引號 """ 包裹多行文字說明。

"""
這是多行註解區塊
可以撰寫詳細說明
"""
print("Hello World")
