1. 變數與記憶體配置 (Variables & Memory)

變數 (Variable) 是程式語言中最基本的核心元素之一。在 Python 中，變數通常是存放在電腦的主記憶體 (RAM) 中，像是一個貼有標籤的盒子用來儲存資料。

📦

記憶體空間 (Memory Box)

變數名稱就像盒子的「標籤」，盒子內部存放數值、文字或布林等資料內容。

⚡

動態型別 (Dynamic Type)

Python 採用動態型別，變數佔用的空間是在程式執行時自動配置，不需事先宣告資料型態。

🗑️

刪除變數 (del Keyword)

可使用 del 變數名稱 刪除變數並釋放記憶體空間。

2. 變數命名規則 (Naming Conventions)

在 Python 中設定識別字（變數名稱）時，必須遵守嚴格的語法規則，否則會導致語法錯誤 (SyntaxError)。

✅ 合法的命名規則

  • 可以使用大小寫英文字母 (A-Z, a-z)。
  • 可以使用阿拉伯數字 (0-9)。
  • 可以使用底線 (_)。
  • 可以使用中文 (Python 3 支援)。
  • 建議使用具有明確意義的名稱 (如 score, student_name)。

❌ 嚴格禁止事項 (Syntax Error)

  • 不能用阿拉伯數字作為開頭 (例：3score)。
  • 大小寫有區別 (Score 與 score 是不同變數)。
  • 不能使用保留關鍵字 (例：for, if, and, as)。
  • 不能包含特殊符號或空格 (例：total-score, my score)。

3. 資料型態與轉換 (Data Types & Conversion)

Python 包含四大基本資料型態。當不同型態進行運算時，常常需要使用轉型函式（Casting）強制轉換資料型態。

int
整數 (Integer)
5, -10, 100
float
浮點數 (Float)
3.5, 0.0, -2.8
bool
布林值 (Boolean)
True, False
str
字串 (String)
'Hello', '8'

三大強制轉型函式 (Type Conversion Functions)

int(x): 強制轉換為整數
float(x): 強制轉換為浮點數
str(x): 強制轉換為字串

4. print() 輸出函式與格式化 (Output Formatting)

print() 是 Python 的基礎輸出函式，可搭配參數自訂分隔與換行，亦支援多種格式化寫法。

print(項目1 [, 項目2, ..., sep = 分隔字元, end = 結束字元])
  • 項目 (item)：可一次輸出多個項目（用逗號相隔）。
  • sep (separator)：項目之間的分隔符號，預設為空白字元 ' '。
  • end：結尾輸出字元，預設為換行字元 '\n'。

🧪 1. sep 與 end 參數調校器

對應程式碼：
print(5, 3.5, 8, True, sep=' ', end='\n')
Console Output 螢幕輸出：
5 3.5 8 True
提示：當 end 被設為空格時，下一次的 print 輸出會接續在同一列後方！

進階格式化輸出：format() 與 f-string

Method 1: 字串 .format()

參數依序填入大括號 {0}, {1}, {2} 中。

# 預設索引或指定位置
print("a={}, b={}".format(a, b))
print("a={0}, b={1}".format(a, b))
Method 2: f-string (現代最推薦寫法)

在字串前加 f，大括號內可直接放變數或指定小數點位數。

# 小數點後兩位格式化 :.2f
print(f"a = {a}, b = {b:.2f}")

5. input() 輸入函式與字串切割 (.split())

使用 input() 讀取使用者輸入。最核心的觀念：input() 取得的所有輸入，資料型態一律為字串 (str)！

💡 數字輸入必須轉型 (Casting)

若需要進行數學運算，必須用 int() 或 float() 包裹：

age = int(input("輸入年齡: "))
w = float(input("輸入體重: "))

✂️ 一次輸入多個變數 (.split())

預設以「空白」進行切割，亦可傳入參數如 .split(',') 改用逗號切割：

a, b = input().split() # 用空白拆分
a, b = int(a), int(b)
