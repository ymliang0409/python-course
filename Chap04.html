流程圖與選擇結構

本章節重點在於學習如何利用 流程圖 與 演算法 拆解問題，並掌握 Python 的 條件判斷與選擇結構，使程式能夠根據不同情況執行相應的邏輯。

1 流程圖 (Flowchart)

流程圖表示法： 將解決問題的步驟與邏輯，用各種標準化的符號圖形來表示。

標準流程圖符號

名稱 圖形符號 意義
起止符號
表示事件的開始或結束
流程符號 表示流程進行的方向
輸入/輸出符號
表示資料的輸出或輸入
處理符號
表示執行或處理的工作
決策判斷符號
表示對某一條件做判斷

流程圖應用範例概念

範例一：過馬路判斷
  • 開始
  • 判斷：號誌亮綠燈？
  • 若 True → 過馬路
  • 若 False → 停下等待
  • 結束
範例二：猜數字遊戲
  • 開始
  • 處理：亂數產生 0~100 之間
  • 輸入：使用者輸入猜測值
  • 判斷：密碼值等於猜測值？
  • 若 True → 輸出「猜對了」
  • 若 False → 輸出「猜錯了」
  • 結束

2 演算法 (Algorithm)

什麼是演算法？

將問題分解成許多小步驟，然後再依一定的次序逐步執行，以解決特定問題的程序。

演算法的五大特性 (Algorithm Features)

1. 輸入 (Input)

外界給予的資料，可有可無 (0 個或多個)。

2. 輸出 (Output)

執行後的結果，至少有一項。

3. 明確性 (Definiteness)

每一個步驟都必須明確而清楚，不會產生歧義。

4. 有限性 (Finiteness)

必須在有限的步驟內完成，不能無限迴圈。

5. 有效性 (Effectiveness)

每一個指令都可行，能在一定時間內推算出結果。

4 單向選擇 (if statement)

唯有當條件式結果為 True 時，才會執行被指定的程式區塊。

語法 (Syntax):

if 條件式:
程式區塊 ← (一定要內縮/對齊)

範例 (Example):

if_example.py
if a == 1:
print("The input is 1")
print("1 is positive")

5 雙向選擇 (if ~ else statement)

條件成立時執行區塊 1；若條件不成立，便會執行 else: 之後的敘述句 (區塊 2)。

語法 (Syntax):

if 條件式:
程式區塊1
else:
程式區塊2

範例一 (判斷奇偶數):

if a % 2 == 0:
print("%d is even" % (a))
else:
print("%d is odd" % (a))

範例二 (判斷及格):

if score >= 60:
print("Pass!!")
else:
print("Fail!!")

6 多向選擇 (if ~ elif ~ else statement)

當有多個條件需要依序判斷時 (else-if ladder)，使用 elif 可以讓結構更清晰。

條件階梯 (else-if ladder) 概念

Condition 1 True → Statement 1
↓ False
Condition 2 True → Statement 2
↓ False
Condition n True → Statement n
↓ False
Else → Statement_else

範例：成績等第判斷

Example
1 g = int(input())
2
3 if (g >= 90):
4 print("A")
5 elif (g >= 80):
6 print("B")
7 elif (g >= 70):
8 print("C")
9 else:
10 print("D")

7 巢狀選擇 (Nested if)

在一個 if 或 else 結構內部，又包含了另一個完整的 if...else 結構，稱為巢狀結構。需特別注意縮排 (Indentation) 以區分層級。

基本語法結構

if condition 1:
if condition 2:
code block 1
else:
code block 2
else:
if condition 3:
code block 3
else:
code block 4
實例示範

範例：車速判斷

1 vel = int(input())
2
3 if (vel > 60):
4 if (vel < 100):
5 print("normal speed")
6 else:
7 print("too fast")
8 else:
9 print("too slow")
