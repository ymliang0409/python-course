2. 演算法 (Algorithm)

什麼是演算法？

將問題分解成許多小步驟，然後再依一定的次序逐步執行，以解決特定問題的明確程序。

演算法的五大特性 (Algorithm Features)

1. 輸入 (Input)

外界給予的資料，可有可無（0 個或多個）。

2. 輸出 (Output)

執行後產生的結果，至少必須要有一個。

3. 明確性 (Definiteness)

每一個步驟都必須明確清楚，不能產生歧義。

4. 有限性 (Finiteness)

必須在有限的步驟內完成，不可陷入無窮迴圈。

5. 有效性 (Effectiveness)

每一個指令都必須切實可行，能在合理時間內算出結果。

4. 單向選擇 (if statement)

唯有當條件式結果為 True 時，才會執行被縮排的程式區塊。

💡 語法結構 (Syntax)

if 條件式:
程式區塊
← 必須嚴格縮排（4個空白）
if_example.py
if a == 1:
print("The input is 1")
print("1 is positive")

5. 雙向選擇 (if ~ else statement)

條件成立時執行區塊 1；若條件不成立，便會執行 else: 之後的區塊 2。

語法結構

if 條件式:
    程式區塊 1
else:
    程式區塊 2

📌 範例一：判斷奇偶數

if a % 2 == 0:
print("%d is even" % (a))
else:
print("%d is odd" % (a))

📌 範例二：成績及格判斷

if score >= 60:
print("Pass!!")
else:
print("Fail!!")

6. 多向選擇 (if ~ elif ~ else statement)

當有多個條件需要依序測試時 (else-if ladder)，使用 elif 能夠建立清晰多分支判斷。

條件階梯 (else-if ladder) 概念

Condition 1 True → Statement 1
↓ False
Condition 2 True → Statement 2
↓ False
Condition n True → Statement n
↓ False
Else → Statement_else

範例：成績等第判斷

Example
g = int(input())

if (g >= 90):
    print("A")
elif (g >= 80):
    print("B")
elif (g >= 70):
    print("C")
else:
    print("D")

7. 巢狀選擇 (Nested if)

在一個 if 或 else 內部包含另一個完整的選擇結構系統，需特別注意縮排 (Indentation) 以嚴格區分控制層級。

基本語法結構

if condition 1:
    if condition 2:
        code block 1
    else:
        code block 2
else:
    if condition 3:
        code block 3
    else:
        code block 4
實例示範：車速判斷 speed_check.py
vel = int(input())

if (vel > 60):
    if (vel < 100):
        print("normal speed")
    else:
        print("too fast")
else:
    print("too slow")
