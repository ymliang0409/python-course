1. 運算式 (Expression)

運算式 (Expression) 是由 運算元 (Operand) 和 運算子 (Operator) 所組成的結構。這是讓程式具備邏輯判斷與資料處理能力的重要基礎。

expression_example.py
Sum = sum + i

⚙️ 運算子 (Operator)

執行操作的符號： = , +

📦 運算元 (Operand)

參與運算的資料或變數： Sum, sum, i

2. 指定運算子 (Assignment operator, =)

基本語法結構：

變數 = 運算式 (常數、變數)
執行程式碼 記憶體中的變數狀態
a, b = 1, 1a = 1, b = 1
a = 10a = 10, b = 1
b = 5a = 10, b = 5
a = b + 3a = 8, b = 5
a = a + 1a = 9, b = 5

🔄 應用：兩數交換 (Exchange)

Python 提供了一種極為簡潔的語法來進行變數值交換，無需像其他語言那樣宣告第三個暫存變數 (temp)。

Python 特色
優雅的交換寫法 a, b = b, a

初始狀態

a = 3, b = 5

執行交換

a, b = b, a

最終狀態

a = 5, b = 3

5. 關係運算子 (Relational operator)

用來比較兩個運算式的大小關係。條件成立回傳 True，條件不成立回傳 False。

程式運算子 對應數學式 意義 運算式範例 結果
== = 等於 (2 == 1) False
!= ≠ 不等於 (2 != 1) True
> > 大於 (2 > 1) True
< < 小於 (2 < 1) False
>= ≥ 大於等於 (2 >= 1) True
<= ≤ 小於等於 (2 <= 1) False

6. 邏輯運算子 (Logical operator)

用於結合多個關係運算式，判斷整體的真偽。

運算子 意義 範例 結果
and 且
(皆為True才是True) 		(5 > 3) and (3 > 2) True
(5 > 3) and (3 < 2) False
(5 < 3) and (3 > 2) False
(5 < 3) and (3 < 2) False
or 或
(其一為True即是True) 		(5 > 3) or (3 > 2) True
(5 > 3) or (3 < 2) True
(5 < 3) or (3 > 2) True
(5 < 3) or (3 < 2) False
not 反相
(True變False) 		not (5 > 3) False
not (5 < 3) True

7. 其它運算子 (Other operators)

成員運算子

in / not in

檢查特定元素是否包含在序列 (如清單、字串或元組) 中。

x = 1
y = [1, 2, 3]

# 檢查 x 是否在 y 裡面
print(x in y) # True

# 檢查 x 是否不在 y 裡面
print(x not in y) # False

身份運算子

is / is not

用來比較兩個物件的記憶體位址是否相同（是否為同一個物件）。

a = [1, 2, 3]
b = [1, 2, 3]
c = a

# 內容相同但記憶體不同
print(a is b) # False

# a 與 c 指向同一記憶體位址
print(a is c) # True

8. map() 函數的應用

map() 函數可以將我們指定的函數（例如 int 或 float），套用到一個可疊代物件（例如串列或元組）的每一個元素上。在 Python 中，它最常用來一次處理多個使用者的輸入值。

語法結構

map(轉換函數, 可疊代物件)
💡 經典情境：讓使用者在同一行輸入多個數字

當我們希望使用者輸入「10 20」，並直接把這兩個數字分別存成整數 a 和 b 時，可以這樣寫：

a, b = map(int, input("請輸入兩個數字(以空白分隔): ").split())
print(f"a + b 的結果為: {a + b}")

步驟拆解：

  1. 使用 input() 取得字串（例如 "10 20"）。
  2. 使用 .split() 將字串依空白切開，變成串列 ['10', '20']（此時還是字串）。
  3. 透過 map(int, ...)，將 int() 函數套用到串列的每一個元素，將它們轉換為真正的整數。
  4. 最後透過多重指定 (Multiple Assignment)，將轉換後的整數分別存入 a 與 b。
