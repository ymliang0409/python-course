第三章
運算子(Operator) 與 運算式(Expression)

在本章節中，我們將學習 Python 中各種常用的運算子，以及如何組合運算元與運算子來建立運算式，這是讓程式具備邏輯判斷與資料處理能力的重要基礎。

1 運算式 (Expression)

運算式 (Expression) 是由 運算元 (Operant/Operand) 和 運算子 (Operator) 所組成的結構。

expression_example.py
Sum = sum + i

運算子 (Operator)

執行操作的符號： = , +

運算元 (Operant)

參與運算的資料或變數： Sum, sum, i

2 指定運算子 (Assignment operator, =)

基本語法結構：

變數 = 運算式 (常數、變數)
執行程式碼 記憶體中的變數狀態
a, b = 1, 1a = 1, b = 1
a = 10a = 10, b = 1
b = 5a = 10, b = 5
a = b + 3a = 8, b = 5
a = a + 1a = 9, b = 5

應用：兩數交換 (Exchange)

Python 提供了一種極為簡潔的語法來進行變數值交換，無需像其他語言那樣宣告第三個暫存變數 (temp)。

Python 特色
優雅的交換寫法 a, b = b, a

初始狀態

a = 3, b = 5

執行交換

a, b = b, a

最終狀態

a = 5, b = 3

5 關係運算子 (Relational operator)

用來比較兩個運算式的大小關係。條件成立回傳 True，條件不成立回傳 False。

程式運算子 對應數學式 意義 運算式範例 結果
== = 等於 (2 == 1) False
!= ≠ 不等於 (2 != 1) True
> > 大於 (2 > 1) True
< < 小於 (2 < 1) False
>= ≥ 大於等於 (2 >= 1) True
<= ≤ 小於等於 (2 <= 1) False

用於結合多個關係運算式，判斷整體的真偽。

運算子 意義 範例 結果
and 且
(皆為True才是True) 		(5 > 3) and (3 > 2) True
(5 > 3) and (3 < 2) False
(5 < 3) and (3 > 2) False
(5 < 3) and (3 < 2) False

not 反相

not (5 < 3) True

7 其它運算子 (Other operators)

成員運算子 (in / not in)

檢查元素是否包含在序列 (如清單、字串) 中。

x = 1
y = [1, 2, 3]
# 檢查 x 是否在 y 裡面 print(x in y) # True
# 檢查 x 是否不在 y 裡面 print(x not in y) # False

身分運算子 (is / is not)

檢查兩者是否為記憶體中「同一個」物件。

x = [1, 2, 3]
y = [1, 2, 3]
# x 和 y 內容相同，但記憶體位置不同 print(x is y) # False
# 檢查是否不是同一個物件 print(x is not y) # True

8 map() 函數的應用

當需要從使用者那裡一次接收多個輸入，並且要同時轉換資料型態（例如從字串轉為整數）時，map() 函數提供了極為簡潔的語法。

傳統寫法

# 步驟繁瑣，需多行賦值
a, b, c = input().split()
a = int(a)
b = int(b)
c = int(c)
推薦用法

map() 簡潔寫法

# 一行完成切割與型態轉換 a, b, c = map(int, input().split())

運作原理解析： 先利用 input().split() 將輸入字串切割成清單，接著 map() 會將第一個參數（即轉換函數 int）自動套用到該清單中的每一個元素上，最後透過多變數指定，將結果分別存入 a, b, c。
